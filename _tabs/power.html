Tomorrow — day-ahead

No day-ahead price here. The EPEX figure on this page is Elexon’s market index MID, published one settlement period at a time, so it never exists for tomorrow. N2EX day-ahead lives on Nord Pool’s API, which sends no CORS headers, so a static site can’t read it from the browser — that needs a server-side fetch, such as a scheduled Action writing a JSON file into the repo. fetching…

What’s plotted. SSP is Elexon DISEBSP system sell price — later settlement runs revise it. EPEX is the Elexon market index MID from APX/EPEX SPOT UK: a volume-weighted within-day index published per settlement period, so it runs up to the current period and no further. Elexon also carries an N2EX market index, but Nord Pool has been submitting zeros to it, so it is deliberately not plotted. Wind forecast is Elexon WINDFOR (unconstrained, BM-registered wind, hourly); metered output is AGWS (onshore + offshore, half-hourly, roughly 2–3 hours behind real time). Forecast sits above output on days with heavy curtailment. Everything is fetched live from the Elexon Insights API in your browser on each load — no key, no cache, nothing stored.
